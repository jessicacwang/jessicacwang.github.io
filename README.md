# hello, I'm Jessica C. Wang

and this is my personal website.

## professionally,

I am finishing up my MS in computational linguistics at the University of Washington, under advisement by [Amandalynne Paullada](https://www.amandalynne.pw/index.html) and [Shane Steinert-Threlkeld](https://www.shane.st/). My project seeks to describe the manifestion of "text quality" for LLM pretraining upon different English dialects and registers. 



### my interests include
- how sociolinguistic theory can inform the development of language technology, and
- what models model about language (broadly construed)
